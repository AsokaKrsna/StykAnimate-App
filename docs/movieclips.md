# Movieclips in the layer timeline

A movieclip is a reusable figure containing a local animation. Insert it on the selected layer, alongside other figures or clips. It does not automatically create a layer. Its internal document has its own layers and frames; Edit movieclip opens that document, Done saves the shared definition, and Cancel restores the parent. Make unique gives the selected frame a separate instance ID and definition, preserving its displayed source frame and the other appearances. Subsequent copies of that unique instance keep its new ID.

Use Animation → New movieclip, Movieclip from selection, or Movieclip from frame range. Selection capture creates a reusable pose; range capture preserves the selected motion. Connected figures are included together. Replacement preserves surrounding figures and draw order. Interleaved selections that cannot be represented by a single container are rejected atomically.

New movieclips follow their presence in layer frames. Inserting a clip adds it to the current pose without extending the scene to fit its source animation. Simple Add carries the same instance forward and advances it. Held exposures advance the internal animation on every output frame. Source duration determines looping, not scene duration.

Missing frames pause the same instance: a clip in scene frames 1, 2, 3 and 5 shows source frames 1, 2, 3 and 4 at matching FPS and speed 1. Object copy/cut and paste within the same document keep a movieclip's ID, playback settings, position and owning layer. Pasting where that ID already exists updates its pose, so repeated pastes never produce duplicate IDs. A paste into a held exposure begins at the selected frame and follows that exposure. Duplicate, library insertion and object paste from another document create independent identities. Ordinary figures still receive new IDs when pasted. Same-layer frame copies keep identity; cross-layer and cross-project frame copies remap identities once per range and retain the copied source phase. Moving frames to another layer retains consumed steps on the source, preserving any later source appearance. Layer visibility and opacity do not affect the clock.

The inspector provides Loop, Once/hold, Once/hide, Single frame, source-frame offset, speed, transform and opacity. Start, End, Restart and Split controls are removed. Inspector playback settings apply to the selected instance across its appearances without inserting time or changing pose-key boundaries. Scrubbing backwards and rendering exports produce the same internal frame as playback.

Deleting a selected movieclip removes it only from the current output frame, including inside a hold. Other clips and surrounding poses remain intact; the missing frame pauses the instance's clock. Applying Delete to selected frames removes only those requested frames' occurrences. Delete on the timeline still removes time according to the normal frame controls.

Break apart frame replaces only the current output frame with editable figures. It preserves every other frame, including the original outer motion curves and unrelated figures on the layer. Adjacent breaks reuse child identities. A continuation record counts the broken frame as a consumed playback step, even after its editable children are moved or deleted. Bake animation expands the instance while preserving prior breaks. Each operation is one undo step.

There are no per-figure clip bars or separate property timelines. Outer posing, clipboard operations, holds and tweens use the layer's frame cells. Several clips can share one row; use another layer when their frame editing needs to be independent.

Definitions live in the figure table as `_styk.movieclip`. New instances use `_stykMovieclip.clock: "presence"`; their stable `unique_id` owns the clock. A cached sparse span index integrates authored presence and speed. `_styk.movieclipContinuations` on retained poses records consumed replacement frames. Layer keys can carry `movieclipPatches`; `patchOnly` boundaries expose those editable frames without adding interpolation control points to the underlying curves. Clipboard, validation, history and source retention include those references. `_movieclipSample` and runtime geometry remain transient.

Existing placement-based project clips retain their saved bounds and phase for compatibility. Newly inserted copies use presence playback. Imported clips may retain source documents to preserve cropped easing exactly; cropped nested presence clips retain their original source phase. Geometry is shared by instances sampling the same immutable definition and time, with bounded local caches.

STYK saving retains the editable nested documents. Pivot export expands the evaluated scene in the worker; image, SVG and video exports use the same evaluator. Existing export limits remain: at most 100,000 Pivot output frames / two million objects, and 5,000 ticks / 250,000 objects for interactive Bake. Pivot cannot represent one opacity operation around overlapping child figures; unsupported expansion still reports that limitation.
